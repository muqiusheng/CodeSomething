- 390px宽的手机展开导航后，菜单底边与正文顶边均为365px。Escape收回并返回菜单按钮。320px工作台分段能单独呈现任务、代码、结果，代码视图中工具栏状态与操作分行。SQL三个分段按钮在320px内完整排列。[手机截图](mobile-navigation.png)

## 辅导与通关

- 未连接工程时显示居中的三步开工卡。HTTP 第2节真实功能检查通过后，用 Enter 跳转到第3节。编辑区聚焦输入时保留原有键盘处理。
- 使用错误路径重新运行HTTP检查，点击求助后已选定位问题和本次报告，代码默认不勾选。发送后，服务端上下文清单包含 workspace-http-text 以及该快照摘要。
- Boot 和 SQL 抽屉可以从课程头部打开。Boot 抽屉跨390px与1366px切换保持打开。SQL 隔离环境的失败报告从报告按钮带入同一次 SQL 尝试。上述三类辅导发送均走实际 HTTP 接口，回答由测试用 app-server 返回，未调用日常账户。
- 后端7项导师测试与前端26项单元测试通过。日常后端切换前备份学习库，启动后逐表比对31张表，记录一致。
