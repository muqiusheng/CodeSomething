# 代码编辑器放大与全项目要求核查

日期：2026年11月16日。当前前端版本0.18.1。

共享CodeEditor增加“放大编辑／还原编辑器”，使用原生dialog顶层显示同一个Monaco实例，避免重复创建导致丢失光标和撤销历史。Esc还原并返回按钮焦点；放大期间锁定页面滚动，手机保留6px边距。普通模式允许从编辑区右下角拖动调整高度。加载失败的文本编辑也使用相同容器。沿用项目主题与按钮，无新增依赖。

共享调用覆盖HTTP、固定Boot、A/B、SQL、生成课程和独立作品。本次真实浏览器直接验证前五类；生成和作品的覆盖依据为相同CodeEditor调用，不记作新增页面实测。
