# 全站学习体验重构首批验收

2026年11月19日。范围为全站重构工作包A–C的首个可试学流程。方案见[docs/34](../../../../docs/34-CodeSomething全站学习体验重构计划.md)。验收前端5208，后端5209，SQLite与临时学习工程独立。

## 基线与兼容

- 日常`/learn`基线显示固定「继续学习」、课表入口和正式任务卡。真实续学记录为HTTP 1.1的`trace/task`。首批验收前后日常该记录及更新时间一致。
- 附件中的`GET /api/v1/reviews`返回404。当前首页实际使用`GET /api/v1/learner/reviews`，基线返回200。故障和成功空队列分别显示；通过浏览器阻断实际请求验证失败和恢复。
- 首访从`/learn`直达`/learn/journey/01`。逐课`/learn/journey/:lessonId`与版本化正式工作台地址继续可用；工作台查询参数`journey`保留课次，`from`保留补练来源，`tab`表示当前查看区域。
- 新增浏览器主动课次记录，旧`cs-journey-position-v1`继续作为回退，服务端正式位置仍可读取。打开课次地址只预览；开始、继续、下一节或明确打开工程工作台保存实际学习位置。由逐课进入的任务页签不覆盖独立的正式会话。通过旧正式任务和浏览器位置时间判断当前目标，正式任务重新选中时以服务端成功保存结果为准。
- 后端使用现行发布JAR。课程发布文件、正式判题规则、工程序号、草稿键与本机目录绑定格式均兼容原有数据。首批只更新前端和课程讲解。
