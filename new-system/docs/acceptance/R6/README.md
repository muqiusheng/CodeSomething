# R6兴趣匹配、生成与发布验收

2026年11月13日，前端0.15.0、后端0.1.0、数据库V12。实现契约见[docs/21](../../../../docs/21-R6兴趣匹配与生成发布契约.md)。

## 交付范围

项目页进入兴趣工作室，读取R5真实画像，比较现有课程、改编题材与AI新方案。草稿有持久状态、幂等创建、部分输出、停止和恢复；通过结构、固定环境构建、三关功能与错误变式门禁后，发布到本机项目库。已发布项目支持完整讲解、递减骨架、真实IDE编码后显式文件导入、隔离检查、摘要时效、服务端理解判定、帮助声明、逐关解锁和续学。

生成域为Java21/Spring Boot内存REST三关：读取40分钟、新增校验50分钟、独立迁移60分钟。题材和资源名可变，接口字段为数字id、字符串title和布尔completed。当前公开研究来源为已固定的三项Java/Spring样例；新上游来源由R6.1工程采集器扩展。IDEA插件继续支持原固定课程，生成项目使用显式三文件导入。

## 真实ChatGPT与隔离门禁

使用本机已有ChatGPT登录，未使用API密钥。真实输入为“图书阅读收藏”，返回结构化题材。原模型输出与最终规范化方案分别保存；最终课程包摘要、固定来源与七项门禁报告见`real-generation-contract.json`、`real-contract-gate.json`。

三关参考实现全部构建并通过外部HTTP断言；三类错误变式分别为错误初始标题、删除空白标题校验、迁移路径错误，均构建成功后被业务断言拒绝。编译或环境失败不能作为有效反例。循环先修、缺失正常/失败用例、构建配置变更在结构门禁处拒绝。

受控提供方测试验证额度错误、非法JSON、部分输出保留、停止、同一草稿重试、重启恢复及发布前拒绝。真实账户额度耗尽和上游物理断网继续保留R1原待验项，受控测试不冒充这些外部事件。

- `browser-phase1.json`：候选模式、画像缺口、焦点转移、草稿刷新与候选/草稿布局。
- `browser-learning-first.json`：原始代码失败→修正通过、文件导入、旧报告、刷新恢复、概念错误不完成。首次axe发现滚动pre不可键盘进入，原始失败证据保留。
- `browser-learning.json`：修正代码/日志区域的tabIndex、region名称与可见焦点后复查；正确理解、帮助不可降级、完成、下一关、首次未完成关卡续学、网络中断重读及普通项目库入口通过。
- 上述记录去重后59个成功断言，其中30组320/375/768/1024/1440px尺寸与六个最终axe场景。最终六个场景均零违规、零待判断。只重跑修复影响的学习区，首次失败与隔离会话重建后需重新导入源码的脚本修正均保留原始记录。

最终教学文本与截图以`learning-final-*`及补充内容记录为准。首次`learning-*`记录的是教学核对前的AI场景，用于保留发现与修正过程。
