# 0.13.1 顶部导航与侧栏反馈

2026年11月12日。用户指出顶部位置文字无法操作、侧栏鼠标高亮有问题并要求加快交互。

## 实现

HeaderNavigation.tsx将“学习空间”改为首页链接，当前位置通过原生details/summary展开七个栏目链接。支持键盘Enter展开、Escape关闭并返回焦点、点击外部关闭、导航后关闭。新增后退/前进按钮，按真实访问顺序工作；刷新恢复已知分支，后退后新建导航清除旧前进分支。首次直接打开页面时，两按钮禁用，应用按钮不会跳向未知站外历史。状态保存在当前标签页的sessionStorage，存储不可用时保留内存导航。

手机顶部采用两行排列，保留当前栏目、后退/前进、快捷搜索、主题切换及正式/演示状态。布局与颜色沿用现有主题。

侧栏移除旧nav伪元素滑动框、JS鼠标位置追踪和图标平移。每个导航项直接以80ms可中断颜色过渡响应，约为此前150—200ms的一半；当前项保持主题选中底色，悬浮其他项只显示轻微基础底色，键盘焦点保留明确轮廓。系统或应用减少动态效果时为0ms。原项目卡片和按钮鼠标逻辑未改。

- 断言覆盖首页链接、栏目切换、后退/前进、刷新、历史分支、键盘与外部关闭、快速连续悬浮、移出、点击更新、命中区域不移动、无滑动层、图标固定、80ms以及减少动态效果。
- 两主题分别检查首页、路径、项目、设置、HTTP课程在320/375/768/1024/1440px的页面及顶部宽度，无整体溢出。

## 发现但未扩大修改的既有问题

初轮在320px HTTP课程打开菜单时，axe报告某段可横向滚动的concept-code没有键盘焦点。此项属于原课程代码组件，与本次顶部/侧栏变化无关，本轮保留为后续键盘可访问性修正。最终菜单审计在首页执行，同时仍保留课程的五尺寸布局检查。

检索本地技能库后优先使用现有daisyui的breadcrumbs/menu与颜色规范、make-interfaces-feel-better的可中断和高频交互规范、agent-browser实测；无新增依赖或动画库。
