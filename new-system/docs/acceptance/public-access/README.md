# 公网账户、权限与管理控制台验收

2026年11月20日。对应 [docs/37 实施计划](../../../../docs/37-公网上线登录权限与管理控制台实施计划.md) 及 [部署说明](../../../deployment/README.md)。前端 0.26.0，后端 0.3.0，SQLite V17。所有验收使用隔离数据库和合成账号。

## 已交付

- 登录、邀请码注册、BCrypt 12、JWT、Secure 刷新 Cookie、轮换与撤销、账号锁定和用户限流。管理员操作包括账号启闭、角色授权、临时密码与强制改密。
- 每账户独立 SQLite。V16 原业务表、主键与历史记录保留在原文件，V17 标记初始管理员归属。认证与后台在主库。服务端学习数据和浏览器草稿均按账户隔离。
- 网页登录与注册、学习路由守卫和管理员路由守卫。公网正式 Java 练习走网页编辑器，既有日常服务保留本机工作流。
- 六个管理界面覆盖概览、用户检索和档案、作业与只读快照、课内实战进度和报告归档、容器与 AI 状态、审计。回收操作按当前部署标签识别容器。
- HTTPS 反代、服务镜像、生产 Compose、rootless Docker 前置校验，以及在线 SQLite 分库备份脚本。

## 续做与部署范围

- 需在目标 Linux 主机验证 rootless Docker、cgroup v2、TLS、DNS、真实客户端 IP 和备份恢复。当前仅执行本机隔离验收。
- 续做版本为前端 0.27.0、后端 0.4.0、SQLite V18。公网 Boot JDBC、项目 A/B 和作品评测接入每作业独立的回环网络。应用与数据库均为只读根盘、512 MiB、1 核、64 PID，学员进程与 Maven 命令分别执行 30 秒上限。数据库管理员密码为每作业独立生成，应用仅获取低权限数据库账号。
- 真实 Docker 专项覆盖 Boot JDBC、项目 A 首关、项目 B 登录关、作品核心与迁移，3 项通过。运行中核对 Java 容器使用作业数据库的网络命名空间、路由表无外部路由、只读根文件系统、512 MiB 和 64 PID 限额。
- 续做全量后端回归 145 项，111 项通过，34 项条件跳过，其中 3 项公网 Docker 专项已单独通过。前端 32 项测试与生产构建通过。
- Linux 容器 Compose 在本机按 2 GiB ECS 模板启动，HTTPS 验证管理员登录、题库和练习池配置。经 HTTPS 提交 Boot JDBC 后通过 9 项断言，管理端读取的源码摘要与判题报告一致。Docker Desktop 烟测使用与守护进程一致的测试卷路径及本地自签名证书，目标 ECS 的 rootless Docker、TLS 与峰值资源仍需实测。
- 新增管理题库和学员补充练习。接口测试覆盖草稿、发布、归档、修订冲突、答案不可预读与学员权限拦截。真实浏览器核对管理员发布、邀请码注册、学员作答与解析。已发布课包继续按现有版本契约维护。
- 公网模式使用模拟 App Server 验证已认证学员可接收 SSE，其他账户不可读取。真实 AI 账号及服务出站配置需在目标环境验证。公网 AI 默认关闭。
- 新增 [2 GiB ECS 模板](../../../deployment/ecs-2g.env.example)。该模板保留 Java 与数据库型 Java 评测，关闭常驻 MySQL 练习池和 AI。启用常驻练习池的部署继续按账户隔离，容器回收后从课程初始数据重建。
