常见问题

适合什么基础？

学过 Java 基础就可以开始。会一点数据库有帮助，HTTP、SQL 和 Spring Boot 会在动手实现项目的过程中逐步学到。

需要在本机配置环境吗？

公网已开放的 HTTP 和普通 Spring Boot 检查可在网页编辑器完成。选择本机工程路线时，可以用 IDEA 编写同一份源码，并按课程配置 JDK 21、Maven 和所需的数据库环境。

为什么采用邀请码注册？

目前开放邀请制试用。持有效邀请码可创建学习账户，登录后进入工作台，使用自己的学习进度和实验记录。

和看视频、刷题有什么区别？

你会从最小配置开始，在同一工程里逐章写代码、运行并检查结果。理解验证和变式复习帮助你回顾实现细节，并练习讲清自己的技术选择。
