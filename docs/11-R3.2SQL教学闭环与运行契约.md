# R3.2 SQL教学闭环与运行契约

日期：2026年11月12日。前端0.11.0，SQL课程sql-foundations/1.0.0。实现范围为数据库环境、六章SQL实践、真实执行、报告、确定性理解验证、正式完成证据、历史记录和跨课程续学。验收结果及运行状态见[R3.2记录](../new-system/docs/acceptance/R3.2/README.md)。

## 用户路径

首页、项目库、学习路径和快捷导航可进入“任务数据实验室”。目录提供六章：连接与识别、任务建表、未完成任务查询、安全增改删、稳定分页、书签迁移。每章包含目标、概念、SQL示例、步骤、预期条件、常见问题和随堂题。单章约30—50分钟，合计240分钟，可分次学习。

用户可在IDE中编写.sql文件，再导入网页；也可直接编辑或粘贴。草稿按课程版本/关卡保存在浏览器，提交内容以不可变文本和SHA-256保存到平台SQLite。网页不会读取其他IDE文件。教学不要求额外购买数据库或API服务。

试运行在cs_practice执行，会改变练习数据，结果不产生正式完成。正式检查在独立临时库执行，按照本关条件比较结果；功能通过后回答新的情境题，两项均通过才保存关卡完成。所有章节可预览，正式完成按SQL六关顺序核对先修；HTTP/JSON推荐先学，不增加跨项目强制解锁。

## MySQL环境与数据边界

实测MySQL8.4.13，固定镜像`mysql@sha256:a81d043930e51745522bd5c430961cf8286f0a23f0a9a2a6e0108f7ea71b0902`。默认容器cs-sql-learning、卷cs-sql-learning-data；验收使用独立容器/卷cs-sql-r32-acceptance，自动测试使用独立临时名称。

采用network none及skip-networking，不暴露宿主机端口；网页由后端通过docker exec调用容器内MySQL客户端，经Unix socket连接。当前不提供IDE数据库面板的TCP直连；IDE可编写文件后导入网页。容器内root只用于受控初始化、授权、重置与清理，不执行学员SQL。没有外部数据库密码要用户填写。容器标签、固定镜像和网络配置不匹配时拒绝操作，启动前不自动拉取浮动镜像。

容器上限640MiB内存、1CPU、256个进程，禁提权并移除非必需capabilities；MySQL关闭local_infile、限制连接数。日常库通过专用账号访问，正式检查使用随机数据库及独立账号，只授予该库的SELECT/INSERT/UPDATE/DELETE/CREATE。平台SQLite不挂载到MySQL容器。

每次检查从版本化种子或空库开始。读取与分页使用两组数据，包含中文、已完成/未完成、相同排序值和非连续编号；读取按顺序比较列及行。写入比较整张表，迁移检查表结构、完整数据及最终查询。空集可在试运行中用不存在编号观察。MySQL命令行显示值为文本，BOOLEAN在表中为TINYINT(1)，默认未完成显示0；界面不将这个0误写为JSON布尔值。

当前课程SQL范围：最多8192字符/12条语句，只支持本课字段和表的SELECT、显式CREATE TABLE和增改删；不支持跨库、注释、客户端命令、外部文件、任意函数、写入子查询、事务控制或通用管理SQL。字符串中的单引号使用两个单引号转义。读取受1.5秒查询限制，客户端5秒超时，结果最多100行/64KiB；超时或停止会终止该账号的MySQL连接。正式检查结束清理临时库/账号。支持范围错误在执行前解释，数据库语法/约束错误单列，环境故障不计为知识错误。

## 初始化与重置

“启动教学环境”异步连接或创建固定容器，确认最终mysqld进程就绪后初始化。启动不会因为用户修改过数据而覆盖现有tasks；重启保留命名卷数据。官方镜像初始化时有临时服务器，因此只验证SELECT 1成功不足以认定最终服务就绪。

重置需要先生成120秒有效的目标预览，明确显示cs_practice和将清空的tasks/bookmarks；取消不执行重置。确认时服务端核对目标、一次性令牌与过期时间。先在cs_reset建立新种子表，再通过RENAME TABLE切换tasks，随后清理旧表与书签；种子准备失败时保留原tasks。重置期间与SQL执行串行，失败可重新预览重试。只操作已验证所属容器里的固定练习目标，未知库和外部连接不能传入。

已实测BOOLEAN默认值与DDL隐式提交：建表会提交此前事务中的写入，ROLLBACK无法撤回这份数据。初始化、检查和重置使用明确数据库边界与清理方案，不以事务回滚覆盖所有DDL。

## API与证据

沿用`/api/v1`与本机来源校验。SQL接口服务本地单用户；目录配对Bearer仍仅用于原Java工作区，SQL文本通过专门入口提交。

| 接口 | 行为 |
| --- | --- |
| GET /courses/sql-foundations/versions/1.0.0 | 固定发布课程及六章；未知版本返回404 |
| GET /sql/environment | 状态、提示、版本、固定镜像、容器与练习库 |
| POST /sql/environment/start | 异步初始化/恢复；轮询环境状态 |
| POST /sql/environment/reset-preview | 目标、后果、一次性token、有效期 |
| POST /sql/environment/reset | target与token均有效后重置；错误目标/过期/重复token拒绝 |
| POST /sql/attempts | courseVersion、stageId、mode、sql、idempotencyKey；保存后排队 |
| GET /sql/attempts?stageId=... | 最新20次快照历史；单个旧快照可按ID访问 |
| GET /sql/attempts/{id} | SQL快照、摘要、状态、报告和理解尝试 |
| POST /sql/attempts/{id}/cancel | 排队立即取消，运行中进入cancelling后释放连接 |
| GET /sql/rules/{stage} | 规则版本及正式情境题，响应不含答案键 |
| POST /sql/understanding | attemptId、版本/关卡/规则、currentSql、answers、幂等键 |
| GET /learning/progress/sql-foundations/1.0.0 | 正式完成证据、数量与下一关 |
| GET /learning/continue及PUT /learning/sessions/local | 原revision契约支持SQL，首页正确续学 |

作业状态为queued/running/cancelling及passed/business_error/sql_error/environment_error/timeout/output_limit/cancelled；试运行成功为executed。启动/报告读取及慢SQL不占用HTTP请求等待时间。平台重启将运行中尝试记为环境中断，可查看快照后重试；排队任务保留。环境重新连接时清理遗留的受控检查库。

V10新增SQL快照/理解尝试/完成/重置令牌表，保留既有V1—V9。报告绑定课程、版本、关卡、SQL摘要、策略、理解规则、种子摘要和镜像；修改后的SQL不能借用旧功能报告完成。先修由服务端按已有SQL完成证据核对。幂等键和唯一约束处理并发重复；同键不同内容返回冲突。新失败不会删除原完成，画像可跳转到完成时的精确快照。

跨课程进度复用相同Progress响应；续学选择当前课程的进度。新课程不会进入原Java运行器：Java工作区预览与作业入口明确拒绝非HTTP课程。SQL完成证据独立关联SQL快照，保留原Java完成表的外键关系。跨课程推荐与能力画像推导仍留R5；开放讲解和长期保留不由一次选择题推断。
