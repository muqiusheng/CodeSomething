# R8 独立作品与首轮验收

2026年11月16日确认：作品C继续围绕同一工程，从设计、编码到测试、部署和陌生需求扩展完成整件作品。全平台都按这个项目原则组织，设计与开放讲解仍保留，不用选择题替代。详见[同一工程项目教学原则](25-同一工程从零完成的项目教学原则.md)。

## 交付边界

作品C是独立任务，不是再给一套逐关答案。首个可执行评价域是有限资源预约：学习者选设备借用、场地预约、活动名额或自己的同类题材，系统固定对外契约与评价规则，内部数据建模、分层、事务和测试由学习者设计。其他业务域可保留选题草稿，不伪称已有自动检查器。项目B是建议先修；未完成可以查看、保存设计和试做，不自动改主线或已有完成证据。

工程仅复用当前系统的固定Java21/Boot/JDBC POM、隔离镜像与快照格式。代码在lab包，可有多个类；不限定表名和分层。应用自行初始化自己的表。检查使用专属MySQL、内网、非root应用账号、受限容器、只读输入与离线Maven。学习者提交RUN.md、JUnit测试及最小启动工程，不提供业务实现。工程测试夹具位于tooling/fixtures，不在作品API提供。

## 外部业务契约 r8-reservation-1

GET /api/health返回200和{"status":"ok"}。POST /api/auth/login接收username、password；初始alice、bob密码Learn-2026!，成功200含token。鉴权使用Bearer token；无效身份401。密码仅为隔离教学账号。

GET /api/resources返回数组，初始id=1容量3、id=2容量2，每项包含id、title、available。资源由应用建模与初始化，重启不能重置库存或预约。GET /api/reservations返回当前身份的预约数组，支持resourceId筛选；不得泄露他人记录。

POST /api/reservations接收resourceId、quantity，正整数quantity，成功201返回id、resourceId、quantity、status="active"。非法输入400、未知资源404、库存不足409。服务端从身份确定用户，忽略客户端userId；成功原子扣减，失败不改变库存。并发争抢不能超卖。

DELETE /api/reservations/{id}仅允许拥有者取消；未知404、他人403。成功204并恢复库存，再次取消204且不重复恢复。错误响应JSON含非空message。GET /返回可操作同源前端（登录、资源、预约和取消），用户提交RUN.md写明环境、表关系、启动/测试/部署、失败处理与设计取舍。自动检查HTML入口、业务重启持久和真实JUnit执行；演示可操作性与开放讲解仍需实际回访。

## 陌生改动

核心检查通过后才发放固定新要求：POST /api/reservations/batch接收预约对象数组，2—5项，成功201返回数组；任一项无效或库存不足整批回滚，重复资源也要累计校验。取消原规则不变。该变式绑定作品、规则与核心快照，发放前不提供逐步实现。迁移检查包含核心回归、成功批量、混合失败回滚及重复资源超额。

## 状态和证据

创建使用幂等键；同键不同题材拒绝。设计以revision乐观并发控制；已确定边界不能静默改题材。每次检查先捕获目录预览（文件清单、摘要），用户确认后提交不可变快照；作业幂等、串行、可停止。报告绑定作品、core/transfer、快照、规则、镜像与检查器摘要；环境异常不评价能力。重启将未完成作业标记interrupted并清理本检查器拥有的资源，允许重新提交。旧报告和历史讲解始终保留，新代码不得冒充旧报告。

开放讲解分别覆盖接口与数据流、并发及失败处理、表关系与取舍、部署与测试；声明none/concept/example帮助并说明来源。记录绑定通过的作业与摘要。长度只用于防空提交，保存状态明确为“待回访核实”，不以字符数认定理解通过。档案归集核心/迁移报告、设计、讲解、帮助、运行文档和回访；仅最新提交通过且讲解绑定最新迁移结果可标记“工程证据齐备”。有示例帮助显示辅助完成。无帮助记录也只表示自述独立，真实独立程度待回访。

首轮回访保存实际观察、日期与自动读取的续学位置、画像快照、真实复习记录数；问题与下一步保留。首次保存是回访记录，不自动判定产品通过。至少24小时后的回访且有实际复习记录才显示“已收集延迟回访”，开放讲解和陌生改动独立性仍由使用者复核。工程验收库与日常库分开，不能导入虚构学习成果。

## 验收

HTTP行为测试覆盖幂等、设计冲突、先修提示、预览、作业绑定、不能提前迁移/归档、帮助与讲解、重启恢复。真实Docker检查验证工程夹具及业务错误、取消/环境失败；浏览器验证创建、保存恢复、提交、报告、讲解、档案与回访，多尺寸和双主题。R8工程完成与真实学习验收分别记录，朋友共享和桌面化须在实际回访后另定。
