# 入门项目与教学组件重构

日期：2026年11月11日。用户提出教学与任务存在大段文字、基础教学缺少项目介绍与递进章节、全站色彩单薄，并补充允许更大胆的设计。此项优先于继续R2.3。插画不在本轮范围。

## 查阅依据与采用方式

1. [AERO：Teach explicitly](https://www.edresearch.edu.au/guides-resources/practice-guides/teach-explicitly)建议把新知识按逻辑分成小步骤，以说明、示范和逐步撤去的指导支持独立实践。采用为“本章目标→概念与示例→操作→随堂判断”，每章集中处理一个新能力。保留必要解释，不把全部正文塞进折叠面板。
2. [Teach Computing：PRIMM教学指南](https://media.teachcomputing.org/QR_11_PRIMM_a57d70eb85.pdf)按预测、运行、调查、修改、创作组织编程教学。采用为同一个Java程序的连续章节：先读懂请求和数据，再运行、追踪、修复，最后迁移到笔记资源。该资料主要讨论学校编程教学；本项目借用其组织方法，不声称已证明本产品对成人自学者的学习效果。
3. [NN/g：Progressive Disclosure](https://www.nngroup.com/articles/progressive-disclosure/)将少用或高级功能放到次级界面，保留主要操作。采用为任务逐步操作面板、按需排错、按需查看骨架；本章目标、当前步骤和验收条件直接可见。任意步骤可回看，个人勾选不构成通过证据。
4. [Carbon：Color](https://www.carbondesignsystem.com/building-blocks/foundations/color/overview)用中性色组织空间，以明确角色管理主操作和辅助色。采用为灰白底色、钴蓝主操作/当前位置、青绿知识与预期结果、杏橙实践提醒、淡紫随堂练习。具体颜色为本项目选择，不是复刻Carbon原值。
5. [W3C：Use of Color](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)要求信息不只靠颜色传达。章节保留编号和名称，当前项有aria-current；步骤有文字与圆形编号，提醒有标题与图标，练习有文字反馈。普通文字按至少4.5:1检查，首轮青绿色不足已加深。

教学技术事实核对[MDN HTTP Overview](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Overview)、[RFC8259](https://www.rfc-editor.org/rfc/rfc8259)和[Oracle JDK21 HttpServer](https://docs.oracle.com/en/java/javase/21/docs/api/jdk.httpserver/com/sun/net/httpserver/HttpServer.html)。其中HttpServer按已注册上下文前缀匹配处理器，因此笔记迁移章明确同时修改createContext前缀与if比较路径。

上述链接均在本轮实际访问。Material3颜色页只返回不可读内容，未以其内容支撑实现；Carbon旧链接404后改用当前官方页面。

## 项目与章节

基础项目名称为“后端入门实验室”，项目页/projects/backend-foundations先说明目标、环境、产物与章节。首页主要入口进入项目介绍，项目库新增基础项目分类，学习路径与快捷导航同步。SQL、数据库与Spring Boot仍属于后续基础单元和项目A先修，本轮没有把它们写成已完成课程。

正式课程新版本为http-json-basics/1.1.0，旧1.0.0与提交记录保留，不迁移或覆盖。

1. 开发准备：区分IDEA、JDK、浏览器，建立独立练习目录。
2. HTTP请求：理解方法、主机、端口与路径。
3. HTTP响应：区分状态码、响应头与响应体。
4. JSON数据：区分字段、值和类型，处理Java字符串与JSON值两层表达。
5. 运行接口：运行完整JDK21骨架，请求自己的Java服务。
6. 代码追踪：根据路径选择分支，把status/body对应到响应。
7. 修复提交：修复两个TODO，核对任务接口约定，保存真实快照。
8. 独立迁移：改成笔记资源，重新定义路径、字段和错误处理并讲解。

每章提供目标、至少两个概念组、具体例子、操作步骤、预期观察、验收清单、常见问题与一道带解析的随堂题。预计时长合计200分钟，是内容规划估算，不是学习效果承诺。先修关系表示建议顺序，章节允许自由查看，没有新增强制解锁路径。

## 组件与状态

- FoundationProject：项目介绍、目标输出示例、三阶段八章目录及后续学习路径。
- ChapterTeaching：目标、概念标题栏、简短解释、代码例子、事实分组与本章实践入口。
- HttpAnatomy：请求拆解、成功/未找到响应对比、代码分支追踪。按钮点选具体部分，邻近解释更新；均标“教学示例”。
- TaskSteps：步骤导航、当前操作、可复制命令、应该看到的结果和个人操作备忘。可前后回看，未强制用户勾选才能继续。
- ChapterQuestion：语义fieldset、选项标签、本次判断和解释。它没有写入能力证据或正式理解尝试。
- WorkspaceSubmission：沿用真实配对、范围预览、快照与幂等作业；新版本按课程版本与章节隔离浏览器缓存。旧版仍使用原绑定键。作业继续显示awaiting_runner。

新任务策略标识为server-smoke-v1、task-json-v1、notes-json-v1，随课程阶段提供。R2.3须按对应课程版本实现策略；本轮没有执行这些策略，也没有把相同JSON格式当成可复用旧结果的依据。

## 设计来源与实现范围

使用ui-ux-pro-max通用规则组织导航/表单/响应式，impeccable bolder/craft-floor作为强化层级参考，agent-browser做实际浏览器验收。ui-ux-pro-max的Python运行时在前轮已确认不可用，本轮没有宣称获得数据库匹配。impeccable引擎缓存不可写，已直接读取项目上下文与指南，没有新装全局引擎。

LeiBox按“章节导航/步骤”及stepper检索两次均SOURCE_UNAVAILABLE，web索引也不可访问；未编造匹配或下载组件。复用已接入的shadcn/Radix Tabs、Dialog等行为，本轮新组件在既有React/CSS体系内实现，无新增运行依赖。已有LeiBox按压按钮保留来源与结构，颜色按新主色适配。

视觉参数集中在design-system.css；学习组件规则放learning.css，避免继续向历史styles.css堆叠覆盖。保留固定侧栏、控制台布局、辅导抽屉、安静的鼠标反馈与减少动效设置。未加入自动播放、粒子、跟随聚光或AI插画。
