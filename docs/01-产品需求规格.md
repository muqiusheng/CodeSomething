# 产品需求规格

2026年11月16日用户最高优先教学要求：所有项目以同一工程从零逐步完成为主线；章节持续增加功能，不重新载入独立关卡代码。讲解与选择题服务于项目开发，选择题可选且不阻挡编码完成。新旧规则冲突时以[同一工程项目教学原则](25-同一工程从零完成的项目教学原则.md)为准。

版本：全新方案1.0；日期：2026年11月10日。

## 1. 学习流程

确认背景 → 环境检查 → 基础模块 → 项目关卡 → 功能检查 → 理解验证 → 保存证据 → 续学/复习 → 阶段回顾与下一项目。

一次约60分钟建议分配：5分钟回顾、10–15分钟教学示例、25–30分钟编码、10分钟检查理解、5分钟记录。时间可调整；超时可保存继续。

## 2. 功能需求

### L01 入门与续学

首次资料预填已知背景，用户确认或纠正。显示A/B/C目标与当前阶段。环境按需检查JDK、IDEA、构建工具、数据库及执行器；未就绪时仍能阅读、操作网页示例。

主页显示主要续学入口、停留位置、关卡状态和可选复习。持久保存内容版本、当前步骤与待办；刷新、重启和AI断开后恢复已成功写入的记录。

### L02 基础教学

每单元包含问题、先修、概念、可运行示例、操作练习、常见误解、理解小题和总结。示例有输入、预期输出与实现原因；课程可独立于AI使用。

首批模块：HTTP/JSON；数据库与SQL；Spring Boot启动、依赖注入、配置、Controller及分层。每单元控制新增概念数量，数据库练习同时检查SQL结果与结构理解。

### L03 项目与关卡

项目显示目标、预计学习次数、先修、最终效果与质量状态。每关对应一个真实开发部分，并标注新知识和复用知识。

前期给骨架补全与修错；中期给接口约定和样例；后期给业务约束，由用户设计。初始题材提案是“个人任务管理”，完整业务可扩展至“学习计划与任务协作”；可按兴趣替换题材。

小项目顺序建议：启动与首个接口 → 参数与校验 → 建模与SQL → 数据访问 → CRUD → 分页筛选 → 统一错误 → 自动化测试。鉴权、角色与部署在项目B引入。

### L04 真实编码与检查

用户在本机IDEA编码。早期绑定项目目录，通过最小本地桥接提交；后续用IDEA插件减少切换。提交前可查看允许文件清单。日志支持定位错误。

提交绑定课程版本与代码快照。结果区分通过、业务失败、编译失败、环境失败、超时与取消。重复点击保持幂等。代码修改或目录变更后，旧结果保留并显示对应版本与过期状态。

### L05 理解与解锁

正式通过需要功能结果与理解结果都有效。理解题改变输入、情境或约束，检查迁移能力；采用输出预测、选择、简短解释或小代码任务，优先确定性判定。

开放解释由AI辅助评价时，给出规则和证据，低置信度进入待复核，允许补充与重答。服务端核对证据后解锁；聊天结论、点击或自报完成不能直接写入通过。

用户可预览后续内容；正式进度遵循先修。查看完整答案可标辅助完成，经独立迁移或重做后更新独立程度。预览、尝试、正式通过分别记录。

### L06 上下文辅导

帮助分为概念提示、问题定位、局部示例/伪代码和完整参考。系统可建议，用户可选择；完整参考由明确动作展开。

上下文包含当前课程片段、选择的代码、有效报告与相关画像证据。显示发送范围，排除凭据与无关文件。支持停止、重试和保留已收到内容。

连接状态包含未配置、等待授权、可用、过期、限额和网络错误。额度不足仍可学习与检查，不自动使用其他付费服务。

### L07 学习画像与调整

画像记录知识状态、最近证据、独立程度、帮助使用、常见错误、目标与兴趣。知识状态采用未接触、学习中、初步验证、独立验证、需要巩固，并显示最后验证时间。

更新从提交、迁移题与独立重做获得证据，保存来源和规则版本。用户可纠正自报背景；自报与实测分开。环境失败、暂停与闲置不降低能力。

小调整可自动且可撤销：提示级别、可选加练、复习顺序。大调整形成提案：换项目、加必修、改目标或明显增加负担；展示原因、前后变化、预计代价和替代选项，用户接受后生效。拒绝后继续原路径。

### L08 主动与推荐复习

根据较久未验证、反复错误及后续依赖推荐复习，解释原因和时长。支持现在做、稍后、跳过；知识列表可主动选题。复习采用变式、修错或小接口，结果追加到证据历史。建议本身不阻断已满足条件的主线。

### L09 调研与新增项目

用户可随时提题材。系统读取画像，再调研公开仓库、教程及技术资料，记录来源日期、技术、规模、先修和可观察范围。“同水平”按能力标签匹配样例，无法确认作者水平时标为相近难度样例。

优先匹配现有课程，再改编，最后生成新课程。推荐说明新知识、复用知识和难度差异。生成经历草稿、结构检查、参考构建、测试、教学抽查与发布；失败保留草稿及原因，现有主线继续。

### L10 作品与阶段回顾

保留需求、接口文档、结构图、运行说明、测试结果、代码版本与讲解问题。作品分为练习中、已完成、可展示。阶段回顾解释已获能力、证据不足处和下一项目建议。

## 3. 状态与一致性

关卡：未开始 → 学习中 → 已提交 → 检查中 → 待修复/待理解验证 → 已通过。异常可重试，每次新建尝试并保留历史。

通过记录关联同一内容版本及相应代码的有效功能结果与理解结果。课程更新保留原通过记录，需要时发补充任务。代码更新生成新快照。

生成：请求 → 研究中 → 方案候选 → 生成中 → 待验证 → 待发布 → 已发布。课程发布与接受路径调整是独立事件。

## 4. 质量验收

Q01：刷新与重启恢复续学、报告和证据。Q02：AI不可用、运行器离线和超时有恢复路径。Q03：键盘可完成学习、提交与理解验证；多尺寸可阅读，IDE编码以桌面为主。Q04：长日志与课程按需渲染，耗时操作立即反馈任务状态并可取消，实测后记录性能。Q05：本地备份可恢复，模型上下文最小化，学习代码与平台隔离。
