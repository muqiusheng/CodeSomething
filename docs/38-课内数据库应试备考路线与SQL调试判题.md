# 课内数据库应试备考路线与 SQL 调试判题

## 两条学习路线

《数据库原理》在 `/school` 的课程卡片提供「实验回顾刷题」和「考试冲刺备考」。实验回顾的七组实验共 177 题，沿用学生选课库。每题提供「运行并判分」，复用考试的执行、基础结果与变式检查，分别计 2、5、3 分。检查点默认折叠，展开后展示期望与实际结果及缺失、多余行。实验一和实验二分别练习 Student、Course、SC，建表题从移除目标表后的沙箱开始，按列、主外键和约束行为验收。手册中的跨库练习使用临时库名映射，预期失败题按原实验语句与 MySQL 错误码评分。满分才记录通过并更新进度。Ctrl+Enter 运行整题并判分。实验「试运行」执行当前选区，未选中时执行整题。两处工作台都可用 Ctrl+Shift+Enter 运行选中代码，从「更多」按语句查看执行轨迹。原实验材料仍可查阅和导出，独立于判题的课程练习库可在对象浏览中查看。两条路线均为每次运行和每组变式创建临时库。

| 页面 | 地址 | 内容 |
| --- | --- | --- |
| 备考大厅 | `/school/:courseId/exams` | 专项卷、模拟卷、草稿续做、整卷成绩、知识点诊断 |
| 作答工作台 | `/school/:courseId/exams/:paperId` | 选择模式，答题卡，收藏存疑，SQL 调试，提交 |
| 阅卷报告 | `/school/:courseId/exams/:paperId/attempts/:attemptId` | 分项得分、耗时、历史、题目解析、SQL 检查点、导出、重练 |
| 错题本 | `/school/:courseId/exams/mistakes` | 按实验、题型、知识点及掌握状态筛选，单题重做和组卷 |

考场默认 90 分钟，可选 60、90、120 分钟或不限时。保持页面打开时，到点会自动交卷。服务端用开始时刻核对截止时间，晚于截止时间只接收已有服务端草稿的交卷请求。刷新后按同一截止时间续考。练习模式开放自查、参考解法、预期差异和语法速查。服务端根据已保存的模式验证核对请求。

考场中通过站内导航或浏览器返回离开当前答卷时，确认框提供继续考试、保存草稿并退出、交卷并查看成绩。保存成功后前往原目的地，计时考试仍沿用同一截止时间。网页刷新和关闭标签页走浏览器原生离开提示。

## 实验错题与通关反馈

- 课程目录为每个实验返回当前版本已保存的未通过题目。仅正式判分为错误或部分得分的题目计入复习雷达，运行环境故障与试运行不计入。再次通过后从待复习列表移除。
- 复习链接通过 `?question=` 定位到对应实验题。首页展示前3道，复习页与个人中心课内页可查看完整列表。
- 实验必做题全部通过时记录通关。在一次有效的正式判分把最后一道必做题变为通过时播放彩带，选做题、已通过题重跑和重新打开实验不播放。更多菜单中可选样式、预览、关闭，选择在当前浏览器保存。

## 按需查看参考答案与解析

实验回顾覆盖按原实验粒度拆分后的所有小题，每道题有自己的参考 SQL 和解析。考试练习覆盖单选、判断、SQL 填空和 SQL 编程。学习者无需先作答、运行或判分。

### 按需接口与防剧透

- SchoolCourseController 提供 `GET /api/school/{courseId}/labs/{labId}/questions/{questionId}/solution`。按课程、实验与题目读取对应配置，返回 `referenceSql` 和 `explanation`。解析说明本题的解题思路或考点。
- SchoolExamController 提供 `GET /api/school/{courseId}/exams/{paperId}/drafts/{draftId}/questions/{questionId}/solution`。服务端按当前账号、课程、试卷及其版本核对草稿和题目，并读取草稿保存的模式和真实交卷记录。练习模式或已有对应交卷记录时允许访问。未交卷的考场草稿请求返回 HTTP 403，考场作答页隐藏入口。交卷后从复盘查看。
- 考试答案响应按题型返回正确选项或判断值、各空的 `acceptedBlanks`，或完整 `referenceSql`，并附 `explanation`。初始题面、草稿响应与考场试运行继续采用现有防剧透规则，查看解析不改变草稿、判分或通过进度。

现有工作台也可使用带 /courses 的课内 API 路径。

### 查看与试运行

- 在 SchoolLabWorkspace 和练习模式的 ExamQuestion 提供次级按钮「查看参考答案」。默认收起，展开时才请求当前题的答案。再次点击收起。切题时关闭面板，迟到的请求结果不得出现在新题。加载失败时可重试。
- SQL 判分反馈提供一处默认收起的「参考答案」，与解析和检查点使用一致的折叠样式。空结果与试运行仅显示运行反馈。答案复用题干处的按需读取、格式化、复制和填入确认。
- 面板展示标准答案和解题思路。单选及判断显示对应选项或判断值，SQL 填空按空位展示标准答案及可接受写法，SQL 编程题以等宽高亮代码块展示完整参考 SQL。
- SQL 编程题提供「复制参考 SQL」与「填入编辑器试运行」。空编辑器直接填入，已有用户代码时先确认覆盖，取消时保留原代码。填入后由学习者主动运行或跟踪。

### 验收

- 新增后端接口测试，核对实验返回 `referenceSql` 和 `explanation`、练习模式四种题型的答案响应、未交卷考场返回 403，以及直接请求不属于当前草稿的课程、试卷或题目时无法读取答案。
- 运行 `./new-system/tooling/backend.ps1 -Action test -TestName SchoolExamCatalogTest,SchoolExamRulesTest`，确认初始题面防泄露校验通过。
- 运行 `npm --prefix ./new-system/frontend test` 和 `npm --prefix ./new-system/frontend run build`。在浏览器核对空白作答时展开、切题收起、复制、填入及取消覆盖，以及考场入口的可见性。

## 课程包与评分

`course-packs/school/database-systems/exams/` 提供 7 套实验专项卷和 4 套期末综合卷。每卷 25 题、100 分，选择、判断、填空、编程分别为 10×2、5×2、5×4、5×10。四套综合卷分别覆盖七个实验标记。275 道当前题干按 Unicode、标点和空白归一化后校验唯一，并与实验标题及任务要求比对。编程题采用 SampleDB（Stock、Salvaging、Out_stock、Prj_cost）与选课库（student、course、sc），部分视图题有预置视图。每道大题的 Markdown 题面包含实际初始化后的字段类型、主外键、约束、默认值和至多两行样例。建表题标出待创建表。桌面编程题在顶部显示快捷题号，左侧固定显示题干、表结构与样例，右侧将执行结果置于编辑器下方。刷题模式的 Ctrl+Enter 运行整题并判分，考场模式仅试运行。完整建表 DDL、单步跟踪及 EXPLAIN 可在「更多」中使用。作答数据只投影公开题干、选项和填空模板。

专项卷升为第 3 版，综合卷升为第 4 版，题目 ID 带版本号。旧定义归档于 `exams/archive/`，用于历史报告的 SQL 复查及错题重练。旧整卷草稿保留已保存作答，打开时提示复制答案后重新开始。新版题目与归档题目可在错题本中分别重做，也可按题目原定义混合组卷。

### 课件对齐

| 综合卷 | 编程考点与课件例题 |
| --- | --- |
| 模拟一 | Salvaging 表与约束（3.1–3.3）、部门与物资聚合（3.39–3.41）、左外连接（3.45、3.48）、子查询更新（3.71）、带检查选项的视图（3.75–3.76） |
| 模拟二 | 自身连接（3.51）、同仓均值相关子查询（3.54）、费用批量写入（3.68）、子查询删除（3.74）、分组视图（3.80、3.85） |
| 模拟三 | 工程成本排名（3.33、3.49）、否定存在性（3.56–3.57）、计算列视图（3.79）、视图更新（3.86）、并集排序（3.61） |
| 模拟四 | 双重 NOT EXISTS（3.59–3.60）、匹配与关联（3.28、3.43、3.50）、复合完整性（3.2–3.3）、嵌套视图（3.78）、状态更新与条件删除（3.71–3.74） |

客观题覆盖数据库三级模式与数据独立性、关系代数与键、SQL、视图、存储过程、触发器及完整性规则。字段依据仓库记录中的第 3 章《数据定义语句》《查询》《数据更新》《视图》课件。抢修记录是为覆盖空集、NULL、边界值、排序并列及同名项目设计的练习数据。例题中的日期差和模式匹配按 MySQL 8.4 语法实现。存储过程专项覆盖第 4 章的输入与输出参数、分支和游标，触发器专项覆盖第 5 章事件、完整性校验和审计。章节重点依据本地课件与本次任务列出的考点。

填空支持 1、2、4 个编号空位。各空均分本题分值。匹配时归一化标识符与关键字大小写、反引号、分号、空白及部分同义运算符与类型名称，字符串字面值保持原意。选项显示顺序存入草稿和交卷快照，判分使用稳定选项标识。

得分达到该次作答满分的 60% 为及格，85% 为优秀。错题子卷按本次题目实际满分计算。

每道编程题按完整执行 2 分、基础结果或对象状态 5 分、变式或行为验证 3 分评分。结果列名比较忽略大小写。变式重放改变输入数据，约束题还会执行合法写入及预期失败的边界操作。检查点支持以下声明。

| 检查点 | 判分证据 |
| --- | --- |
| `execution` | 语句脚本完整执行 |
| `result_set` | 结果列、行及可选顺序规则，按多重集合保留重复行计数 |
| `post_query` / `state_check` | 执行脚本后查询表、视图、过程结果或 MySQL 元数据 |
| `negative_check` | 正例成功、反例返回任一预期错误码，反例前后状态一致 |
| `variantSql` | 同一检查点在独立种子变体上再执行，测试数据改变后结果仍正确 |

SQL 报告包含每步分值、诊断、期望与实际结果以及行差异。运行器停用或不可用时，已作答的 SQL 题保留为待判。客观题、填空和提交快照正常保存，待判题暂不计入错题本和薄弱诊断。

## MySQL 沙盒

判题、调试与原实验使用同一个课内容器键。每个沙盒创建随机命名的 `cs_exam_<hex>` 库与本地临时用户，仅授权当前临时库；库授权转义下划线，专用前缀为平台保留。题目种子数据、可选初始化 SQL 和判题探针来自可信课程包。学员脚本和探针均由临时用户执行，参考脚本使用同条件独立库。同题的数据变体批量建库和回收，各变体使用独立账号。正常退出合并删除数据库和用户，超时、超限或取消时先终止临时用户连接。运行命令使用通过校验的容器 ID，连接失败时重新验证容器并恢复。

调试支持整段、选中片段、单步跟踪、EXPLAIN、表结构与种子数据预览。选区用其起始行换算错误位置。单步跟踪在同一个 MySQL 会话中顺序执行，包括 DELIMITER 例程和触发器，捕获语句级耗时、结果、影响行数以及动态发现的基础表变化和最近预览样本，涵盖预建表、新表和新增列。表结构预览读取初始化后的基础表和视图。每次执行从干净沙盒开始。重置本题沙箱清除本题的调试与判分反馈，保留当前 SQL。实验通过记录随作答保存，重置本题显示不影响历史记录。清空代码需确认。MySQL 客户端错误保留原文并提供中文建议。

脚本遵循 8192 字符、最多 32 条语句、1500 ms 的 SELECT 限时、101 行的服务端 SELECT 上限、每结果表 100 行可比较上限、CLI 6 秒和 64 KB 输出限制。SQL 本身的事务提交与回滚由 MySQL 执行。语句级调试会注入观测语句，依赖上条语句元信息的 SQL 应以真实脚本运行结果为准。查询结果使用 MySQL XML 输出。含空结果且需核对字段时，使用新沙盒回放并补读 MySQL 字段元数据。参考结果按课程、题目、种子与判题内容摘要缓存，结构预览按课程、题目与初始化内容摘要缓存。目录文件名、大小和修改时间控制题库解析缓存失效。探针按变体合并执行，学员脚本使用独立连接，保留原事务退出语义。

MySQL 语法与边界参见 [MySQL 8.4 客户端命令](https://dev.mysql.com/doc/refman/8.4/en/mysql-commands.html)、[存储程序限制](https://dev.mysql.com/doc/refman/8.4/en/stored-program-restrictions.html) 和 [EXPLAIN 输出](https://dev.mysql.com/doc/refman/8.4/en/explain-output.html)。

## 存储与复练

Flyway V23 增加草稿、提交、提交题项和错题表。V22 由注册邮箱限制的 Java 迁移使用。公网学员读写自己的 SQLite 学习库，服务端验证草稿 revision 并在一次事务中写入不可变提交及错题变更。重复提交同一交卷 ID 返回相同报告。每卷保留一份活动草稿，可在确认后以 revision 校验放弃并重开。已到期后才打开的考场可手动提交保存内容或放弃。旧版模拟卷草稿可复制原作答并明确放弃，已交报告和历史错题保留原题面与答案。首次进入草稿后浏览器按账号与草稿 ID 保存会话备份，只在服务器版本相同时恢复。

完整重练创建独立作答和历史成绩。仅错题重练使用所选报告的未满分题，按子卷实际满分评分。错题组卷按当前筛选与顺序取最多 25 题。错题保存最近错误、源卷和计数，重练满分自动标记已掌握，后续错答重新归入待攻克；支持手动调整。知识点正确率按每题最近一次有效交卷作答的得分与满分聚合，可跳转实验、专项卷和错题筛选。

接口见 [Backend API](../new-system/backend/API.md)。验收记录、测试命令与证据见 [数据库备考验收目录](../new-system/docs/acceptance/school-exams/README.md)。
