# R5画像、复习与阶段调整

2026年11月12日。范围为R5.1—R5.4，沿用HTTP/JSON、SQL、Boot和项目A已发布版本、正式双结果与先修规则。工程实现位于`new-system/backend/.../profile`及`frontend/src/features/profile`、`features/reviews`。

## R5.1 证据与可解释画像

覆盖19个正式代码关卡：HTTP/JSON三关、SQL六关、Boot四关、项目A六关。已有正式完成记录提供来源ID、课程版本、代码/SQL摘要、理解规则和时间；失败报告提供实际检查策略及检查器/规则摘要。已交付内容非空的示例辅导单列帮助证据，不把请求失败、未生成回答或未来的辅导反算为过去完成时的帮助。

`learner_evidence`在读取画像时从已持久化来源按关卡/类型/来源ID追加归一化证据，重复读取不重复追加。`learner_mastery_snapshots`保存规则`r5-1`、完整判定材料、来源ID与SHA-256指纹；材料不变时复用快照ID。原始关卡记录、提交及快照不被画像覆盖。

判定优先级：用户最新异议→待核实；最新有效复习错误或最近重复代码/业务错误→需要巩固；有正式双结果且记录到此前示例帮助或用户声明借助答案→辅助完成；有正式双结果→课程已验证；其余→尚无正式完成证据。编译/业务/SQL错误计入练习问题，环境故障单列，取消、超时和闲置不扣减能力。用户撤回纠正后重新依据实际证据判断。复习答对可解除此前概念巩固建议，历史错误仍可查看。

帮助记录是平台可观察范围；没有帮助记录不等于已经证明独立编码。画像和阶段回顾保留独立编码/开放讲解待验证状态，选择题不生成独立项目通过。真实学习回访沿用R3/R8验收边界。

纠正分为提出异议、声明借助答案、撤回纠正，须有1—500字理由。按操作编号幂等，编号与内容冲突返回409。自报纠正与实测证据并列保存，不允许通过纠正直接增加正式完成数。

## R5.2 主动与推荐复习

19关各有两道独立编写的概念迁移题，共38题，位于`ReviewQuestions.java`，与正式理解题分开。每轮保存规则、关卡、题号、帮助等级、开始时间、答案、判定、结束时间和下次建议时间。开始或恢复未作答轮次不下发正确选项与解析；提交后由后端评分并返回解析。

同一关同时只存在一轮开放复习；重复开始恢复原轮次。重复提交相同答案及帮助等级返回同一结果，改变已结束结果返回409。答题时可上调实际帮助等级，不能降低已声明的帮助。刷新后可从最近记录恢复未完成题目。

完成课程满一天或存在巩固/异议建议时进入推荐。自行答对后三天再建议，借助帮助答对或答错后一天再建议；这是当前可解释的产品规则，不是精密记忆预测。稍后一天、跳过七天会保存安排并暂缓推荐，用户仍可主动开始。没有记录时提供主动选题，不编造薄弱点。

概念结果区分即时答对、相对课程完成至少延迟一天答对、借助帮助答对、待巩固和重复变式答对。已经揭示过答案的相同变式再次出现时明确记为重复练习。当前题库为每关两题轮换，不宣称无限新题；新题或评分规则改变时须保留旧版本可解释性。

画像复习不写正式完成表、学习位置或关卡先修。首页读取真实复习队列，侧栏不再保留硬编码的复习数量。

## R5.3 可预览的调整与撤销

当前支持两种可选安排：每日一题（每日额外五分钟）、集中巩固指定课程（每日额外十五分钟，并在复习建议中优先该课程）。主线每日时长、课程顺序和先修不变。两种安排均先展示前后时长、课程、理由和影响，由用户接受后生效；不自动增加本人的学习负担。

提案保存原计划、预期版本、状态与应用版本。拒绝保持原计划；接受及撤销幂等。计划已经有后续变化时，旧提案不能被接受，旧调整不能覆盖新计划，须生成新的提案。撤销恢复此前额外复习时长及优先课程并递增版本。复习页按已接受时长展示约1或3项当日建议，未设置时提供1项按需建议及全部关卡选择。

## R5.4 阶段回顾

按四门课程聚合正式完成数、真实辅导记录数、已完成变式复习数和下一未完成关卡。课程双结果齐全时，建议独立复现、说明数据流与完成陌生小改动。独立编码与开放讲解保持单列，不用概念复习替代项目能力证据。

## API与持久化

以下接口均为本地单用户范围，沿用来源限制、统一错误与SQLite事务。

- `GET /api/v1/learner/profile`：画像、规则/快照ID、按课程回顾、当前复习计划。
- `POST /learner/corrections`：关卡、类型、理由及幂等编号。
- `GET /learner/reviews`：推荐/主动队列、最近30轮及当前计划。
- `POST /learner/reviews`：按关卡与帮助等级开始/恢复。
- `POST /learner/reviews/{id}/answer`：答案与实际帮助，评分并保存。
- `POST /learner/reviews/{id}/defer`：`later`或`skip`。
- `GET/POST /learner/adjustments`：查看历史或生成具体提案。
- `POST /learner/adjustments/{id}/decision`：`accept`、`reject`、`undo`。

V11追加画像证据、快照、纠正、复习、计划和提案表，不更改V1—V10及发布课程内容。前端`/profile`、`/reviews`及首页入口使用真实接口。加载、空、失败、重试、忙碌及成功均保留文字反馈。

实际测试、升级、浏览器、重启及日常服务切换结果见[R5验收](../new-system/docs/acceptance/R5/README.md)。
