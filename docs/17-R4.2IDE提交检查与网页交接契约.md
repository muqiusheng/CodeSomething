# R4.2 IDE提交、检查与网页交接

2026年11月12日。插件0.2.0、前端0.13.3，沿用R4.1实测的IDEA2026.2（IU-262.8665.258）与本机SDK构建入口。

## 用户流程

当前工程预览并配对后，工具窗口保留课程、关卡、允许文件及SHA-256。点击“提交并检查”先在EDT保存工程内未落盘文档，再在后台读取当前授权摘要、保存不可变快照并创建检查作业。后端继续检查允许范围和摘要变化，插件不执行学员构建脚本。

同一窗口内，快照保存成功但作业创建响应丢失时，按钮变为“重试启动检查”，复用快照和幂等键；成功后下一次提交创建新快照。运行中禁用切换课程、关卡、端口和重复提交，保留刷新、取消及网页入口。每1.5秒读取作业，服务异常停止自动轮询并保留作业供手动刷新；项目或工具窗口释放时停止轮询。

报告页展示作业、快照、状态、课程版本、逐项预期/实际、摘要与运行日志。功能通过仍需网页正式理解验证。环境失败、取消和超时沿用后端消息。读取报告时保留后端freshness/stale提示；持续监听文件变化与重启恢复接R4.3。

## 错误定位

从javac的`File.java:行:列`、Maven的`File.java:[行,列]`和Java堆栈的`(File.java:行)`提取位置。行列从1起算，IDE打开时转为0起算。文件必须唯一匹配本次快照允许清单，并是当前工程内普通真实文件；拒绝路径穿越、符号链接、目录联接及重名歧义。跳转前再次核对文件。只有业务断言而无源码位置时展示预期/实际和完整日志，不推断行号。

使用本机SDK的`LocalFileSystem`与`OpenFileDescriptor`完成真实编辑器跳转。在线JetBrains文档本轮请求返回404，接口以实际SDK编译与沙箱验证为准，没有引用未读取的在线内容。

## 网页交接

网页标签页与IDE PasswordSafe分别保存配对凭据。“在网页查看报告”显式创建一次性交接，打开同一课程任务；网页在React挂载前消费临时码，将配对及提交写入当前标签页会话，读取同一作业。Boot/项目A还保留指定submission/job查询参数，可继续正式理解验证。

新增接口均沿用本机Host/Origin检查与application/json写入约束：

| 接口 | 约定 |
| --- | --- |
| POST /api/v1/ide-handoffs | Bearer鉴权；bindingId、jobId必须对应同一提交绑定；返回code、expiresAt，不返回令牌 |
| POST /api/v1/ide-handoffs/consume | 提交code；单次消费返回binding、课程版本/关卡、submissionId和jobId；失效或重用返回409/HANDOFF_EXPIRED |

临时码由两个随机UUID组成，60秒有效；以摘要为索引保存在进程内，最多64项，同一绑定新交接替换旧交接，创建/消费时清理过期项。待消费项在进程内暂存凭据，不落库；后端重启使全部临时码失效。创建和消费响应均为Cache-Control:no-store。URL片段只携带临时码；网页在请求前移除片段，URL不含配对令牌。失效或浏览器存储失败时打开任务页展示重新从IDE打开报告的恢复提示。

## 验证与接续

验收使用5191后端、5179网页、独立SQLite、参考工程副本和IDE沙箱，未向日常IDE安装插件。沙箱采用与R4.1相同的基础平台模式，禁用Ultimate模块；本插件不依赖Ultimate功能。实际通过范围和截图见[R4.2验收](../new-system/docs/acceptance/R4.2/README.md)。

R4.3接配对/作业重启恢复、断线后恢复、目录移动重新绑定、持续的旧结果标识和绑定生命周期。标准Gradle完整构建仍保留R4.1待验项；当前交付包使用已验证的本机SDK入口。
