2026年11月17日0.22.0：运行位置与回退规则以[本地运行优先与检查环境回退](29-本地运行优先与检查环境回退.md)为准；本页的工程读取、原POM、快照与完成核对规则继续有效。

当前有效版本：2026年11月17日0.21.0。网站引导学习者在独立目录中创建、开发同一份工程，读取项目并检查章节功能。界面、文件存储与检查器使用同一份工程事实。

## 学习流程

1. 在网站目录之外创建自己的工程。Boot项目可以使用Spring Initializr，选择Java、Maven、JDK17至21及相应依赖；包名、项目名、启动类名自行确定。课程最小配置与源码路径是参考示例，不要求复制平台的lab包或Application类名。HTTP单文件入门继续按任务约定在根目录编写TaskServer.java。
2. 首次点击选择项目根目录，在桌面Chrome/Edge中授权读写。网站按课程与版本将原生目录句柄记入IndexedDB；同项目后续章节、刷新和回看自动恢复。浏览器回收授权时重新授权，保持已选工程位置。
3. 右侧显示完整目录，按需展开所有文件和子目录。点击文本文件打开共用编辑器；大文件、二进制或无法按UTF-8解码的文件提示在本地应用打开。网页修改使用保存到本地写回原文件；提交前也先保存。检测到IDE外部改动时拒绝覆盖，网页修改保留；显式丢弃后可以恢复。
4. 提交自动从磁盘重新读取检查范围：Boot包括pom.xml、main/test中的Java和支持的文本资源、RUN.md；HTTP包括任务文件。IDE配置、构建产物、根目录.env与无关文件不参与检查。无需勾选文件，不将浏览器缓存当作磁盘最新内容。
5. 检查按实际项目打包产物运行，依据章节接口、状态码、数据与持久性契约判定。依赖准备失败、编译失败、应用启动失败、业务不符、超时和取消分别反馈；只有真实通过报告可以用于完成记录。
6. 点击完成本关编码时再次读取磁盘并核对报告；修改后的文件不能沿用旧通过记录。完成后下一章继续同一目录；回看旧章保留最新源码，并标明历史快照过时。

## 工程快照与运行环境

- 前后端均校验安全相对路径，允许任意常规Java包层级与启动类名。快照保留原始pom.xml及文件内容，所有参与检查的文件都影响摘要。文件最多100个，单文件64KiB，总文本源码2MiB。
- 支持src/main/java、src/test/java，以及main/test的resources中的properties、yml/yaml、xml、json、sql、txt、md、html、css、js、csv等文本资源。完整目录展示与提交范围分别处理。
- 已有课程依赖继续复用锁定镜像。其他正常Boot 3/4配置先提取依赖声明，在不含用户源码的临时容器准备依赖和标准构建工具；不在宿主机执行用户构建。缓存按声明与工具链摘要复用，首次需要网络。实际用户源码仍按原pom.xml在非特权、只读根文件系统、限制资源和网络的容器中离线构建。不会以平台版本替代用户版本后标记通过。
- 运行器使用工程实际生成的JAR名称；数据库练习使用独立内网、临时库和限定账号，用户真实数据库不作为判题数据库。报告保留源码摘要、课程策略、镜像与探针证据。
- 单模块Boot正式版本与常规Maven插件为当前范围。聚合模块、外部父POM、Gradle、自定义构建扩展或超出JDK版本范围会显示具体配置问题，不自动改写工程。无可用依赖或无法核实环境时不产生通过记录。

## 项目入口与其他功能

HTTP、Boot及项目A/B使用统一目录工作区。生成项目与独立作品的导入和检查同样移除固定包和固定POM限制；它们继续保留各自作品/生成流程。SQL保持脚本导入与隔离SQL检查。Tlias继续作为资料实战与本地自查项目，尚无自动判题，读取和手动自查不产生能力通过记录。

## 本机接口

POST /api/v1/local-ide/open仅启动服务端已配置的IDEA程序，不接受客户端命令。限定回环访问，复用Origin检查并限制重复请求。设置CS_IDEA_EXECUTABLE或CS_IDEA_HOME后由启动脚本解析；可手动打开IDE继续。

GET /api/v1/workspace-bindings/{id}/sources要求原配对Bearer凭据，返回允许范围的digest与files；expectedDigest不匹配返回409。IDE旧交接、浏览器授权工程和历史报告继续保留各自凭据，不开放工程外任意路径读取。
